# pokedex-typescript-lite
Pokédex TypeScript Lite é uma aplicação back-end simples em Node.js com TypeScript, que consulta dados de Pokémon na PokeAPI e organiza os resultados em um catálogo local. O sistema permite buscar Pokémon por nome ou ID, mapear os dados em objetos tipados, salvar em catálogo,executado via terminal e documentado com README completo, GitFlow e Kanban
